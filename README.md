# 📄 ResumeForge — Modern Resume Builder Web App

A modern, responsive resume builder web application built with a sleek **Blue & White UI**.

---

## ✨ Features

- 🎨 **Modern Blue & White UI**: Clean, glassmorphic header, tailored color palette, polished inputs, and smooth transitions.
- 📑 **2 Handcrafted Resume Templates**:
  1. **Plain Classic (Black & White)**: Minimalist, clean ATS-friendly layout with serif typography, zero color fills, and clear section dividers.
  2. **Modern Blue (Vibrant)**: Eye-catching cobalt & azure gradient header, dual-column structure, sleek timeline nodes, and pill badges for skills.
- 📝 **Comprehensive Sections**:
  - Personal Information & Contact Links (LinkedIn, GitHub, Portfolio)
  - Executive / Professional Summary
  - Dynamic Work Experience (+ Add / Remove)
  - Dynamic Education (+ Add / Remove)
  - Skills & Competencies (comma-separated tags)
  - Key Projects (+ Add / Remove)
  - Certifications & Honors (+ Add / Remove)
- ⚡ **"Generate Resume" Button**: Instantly updates and formats the resume preview. Live preview typing synchronization is also included.
- 📥 **Instant PDF Download**: One-click download as a high-quality PDF using `html2pdf.js` with smart naming (`Candidate_Name_Resume.pdf`). Also features a direct vector print option.
- 🚀 **Preloaded Sample Data**: Click "Load Sample" to instantly populate the form and see the resume in action!

---

## 🚀 How to Run

### Option 1 (Easiest — No Server Required)
Simply double-click **`open.bat`** or double-click **`index.html`** in your file explorer. It will open directly in Google Chrome, Microsoft Edge, or any modern web browser.

### Option 2 (Via Localhost)
If you prefer running via a local web server:
```bash
# In this folder:
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
